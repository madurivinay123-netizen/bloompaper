# 🌱 BloomPaper — Plantable Seed Paper Invitations & Stationery

> **"Invitations that never end in the trash — they bloom into wildflowers."**

A luxury web application for handcrafted, plantable seed paper wedding invitations and eco-stationery. Handcrafted from recycled cotton fibers and embedded with living, non-GMO pollinator seeds (marigolds, lavender, chamomile).

---

## ✨ Features

- **🌸 Interactive Botanical Hero & Live Sprouting Demo**: Interactive seed paper that demonstrates watering and real-time plant growth.
- **🎬 3D Cinematic Storyboard Video Player**:
  - 6-scene interactive storyboard walkthrough.
  - Smooth Ken Burns canvas animations, floating petal physics, and ambient nature piano audio synthesizer.
  - Video export/download capabilities.
- **📜 3-Piece Ensemble Showcase (Gallery)**:
  - Continuous auto-scrolling marquee gallery with pause-on-hover.
  - Modal inspection showing the complete 3-piece luxury ensemble:
    1. **Outer Designer Jacket Cover**
    2. **Inner Information Sheet**
    3. **Living Plantable Seed Paper Sheet**
- **🧮 Dynamic Bulk Pricing Calculator**:
  - Live calculations in Indian Rupees (₹).
  - Bulk tiered discounts (10% to 25%), custom foil finishes (Gold, Rose Gold, Blind Deboss, Botanical Green), and express planting kits.
- **📝 Custom Design & Sample Kit Request**:
  - Interactive design selection drawer with 10+ handcrafted Indian wedding and celebratory suites.
  - Preloaded specs and instant ordering workflow.
- **⭐ Community Reviews & Ratings**:
  - Customer review modal with verified buyer feedback and photo gallery.
- **🔐 Authentication & Sample Kit Modals**:
  - Responsive modals for account login/registration and free sample kit requests.

---

## 🛠️ Tech Stack

- **Framework**: React 18
- **Build Tool**: Vite
- **Styling**: Vanilla CSS (Tailored luxury botanical color system, glassmorphism, responsive)
- **Icons**: Lucide React
- **Audio & Visuals**: Web Audio API Synthesizer, HTML5 Canvas 2D particle systems

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone <your-repository-url>

# Navigate into the project directory
cd new_paper_seed

# Install dependencies
npm install

# Start development server
npm run dev
```

The application will be live at `http://localhost:5173/` or `http://localhost:5174/`.

### Build for Production

```bash
npm run build
```
